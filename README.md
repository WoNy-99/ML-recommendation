# Restaurant Recommendation System

사용자의 위치와 선호 카테고리를 바탕으로 레스토랑을 추천하는 머신러닝 팀 프로젝트입니다. 이 저장소는 팀 저장소를 fork한 개인 포트폴리오용 저장소입니다.

## 프로젝트 구성

- TF-IDF 기반 콘텐츠 추천
- SVD 기반 협업 필터링
- 위치·카테고리·평점 신호를 결합한 하이브리드 추천
- Recall@10, nDCG@10, MAP@10과 카테고리 적합도로 평가

## 담당 내용

- TF-IDF 기반 추천 모델 설계 및 구현
- 사용자 리뷰·카테고리 텍스트 벡터화
- 코사인 유사도를 이용한 후보 레스토랑 산출
- TF-IDF 모델의 오프라인 평가와 결과 정리

## 주요 결과

| Model | Users | Recall@10 | nDCG@10 | MAP@10 |
|---|---:|---:|---:|---:|
| TF-IDF | 375 | 0.0267 | 0.0149 | 0.0116 |
| Hybrid | 1,270 | 0.1189 | 0.0961 | 0.0549 |

TF-IDF 모델은 OpenTable 카테고리 적합도 기준 Hit@10 약 0.41을 기록했습니다. 이후 팀의 하이브리드 모델은 협업 필터링과 위치·콘텐츠 신호를 결합해 Recall@10을 크게 개선했습니다.
